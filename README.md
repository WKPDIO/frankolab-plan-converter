# FrankoLab · конвертер плану лікування

Перетворює план лікування з ClinicCards (PDF) на зрозумілий пацієнту PDF у стилі FrankoLab:
етапи й блоки, просте пояснення кожної послуги з картинкою, зубна формула кожного етапу,
пам'ятки перед і після процедур, кошторис у гривнях і євро. Кожна сума звіряється з оригіналом —
якщо хоч одна не збігається, конвертер зупиняється і нічого не видає.

## Як це працює

```
PDF з ClinicCards ─► parse_clinicards.py ─► render.py (довідник послуг) ─► templates/plan.html.j2 ─► PDF
                     читає етапи, блоки,     описи, картинки, «У ціні»,     верстка, шрифти,
                     зуби, ціни, знижки      кольори, пам'ятки, формула     кольори бренду
```

Коли з'явиться API ClinicCards, міняється лише перший крок — усе інше лишається.

## Файли — і що де міняти

| Файл | Що в ньому | Хто може міняти |
|---|---|---|
| `data/services.json` | довідник послуг: опис (`desc`), картинка (`pic`), що входить у ціну (`incl`), мітка «наша лабораторія» (`lab`), що малювати на зубі (`effect`); категорії блоків з кольорами фону; загальна примітка (`included_everywhere`) | адміністратор / лікар — це текст |
| `data/memos.json` | пам'ятки пацієнту: коли показувати (`trigger`), де (`before`/`after`), пункти | адміністратор / лікар |
| `templates/plan.html.j2` | верстка сторінок, шрифти, кольори, порядок розділів, таблиця | розробник |
| `illustrations.py` | 38 ілюстрацій процедур (SVG) | розробник |
| `stagechart.py` | зубна формула етапу: як кожна процедура малюється на зубі, легенда | розробник |
| `graphics.py` | анатомічні форми зубів, загальна зубна формула, іконки блоків | розробник |
| `parse_clinicards.py` | читання PDF з ClinicCards | розробник |
| `examples/` | 5 знеособлених планів для перевірки після змін | — |

## Запуск

```bash
pip install -r requirements.txt
python3 -m playwright install chromium

# один план (PDF з ClinicCards або розібраний JSON), за бажанням — панорама
python3 render.py plan.pdf out/ panorama.png

# перевірка після будь-яких змін: перезбирає 5 прикладів і звіряє суми
python3 check_examples.py

# аркуш з усіма ілюстраціями → out/illus.png
python3 preview_illustrations.py 8
```

Для сайту чи іншої програми є функція `render.render_plan(src, out_dir, pano=None)` —
повертає шлях до PDF і звіт (кількість позицій, суми, послуги без опису).

## Правила

- **Дані пацієнтів у репозиторій не кладемо**: ні PDF, ні панорами, ні розібрані плани з іменами.
  Для тестів — лише знеособлені приклади в `examples/`.
- **Після кожної зміни** — `python3 check_examples.py` і погляд на PDF у `out/examples/`.
- Тон описів — за брендбуком: просто, спокійно, без обіцянок («гарантовано», «100 %», «безболісно»),
  без тиску. Конвертер сам попереджає, якщо такі слова з'являться в описах.
- Нова послуга без опису не ламає план: вона виходить без пояснення, а конвертер повідомляє, що опис треба дописати.

## Відкриті питання

- All-on-4 (€2 500): чи входять у ціну всі чотири імплантати — до відповіді рядок «У ціні» не показуємо.
- «Коронка/накладка склокерамічна» на зубній формулі малюється як коронка (`effect: crown`).
